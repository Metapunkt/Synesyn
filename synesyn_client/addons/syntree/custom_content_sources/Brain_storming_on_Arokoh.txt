How do I use content in / from / through ContentManager?

Great question! The ContentManager is designed to store and manage content that can be used throughout your Arokoh system. Here's how you can use content from the ContentManager:

1. Adding Content:
   You can add content to the ContentManager using the `add_content_source` method. This is typically done when initializing your application or when new content is created or loaded.

   ```gdscript
   Global.get_content_manager().add_content_source("key_name", "Content goes here")
   ```

2. Retrieving Content:
   To get content from the ContentManager, you can use the `get_content` method:

   ```gdscript
   var content = Global.get_content_manager().get_content("key_name")
   ```

3. Getting All Content:
   If you need all the stored content, use the `get_all_content` method:

   ```gdscript
   var all_content = Global.get_content_manager().get_all_content()
   ```

4. Using Content in Other Managers:
   You can pass content from the ContentManager to other managers for processing. For example:

   ```gdscript
   var content = Global.get_content_manager().get_content("story_draft")
   var analysis_results = Global.get_analysis_manager().analyze_text(content)
   ```

5. Updating UI with Content:
   You can use the content to update your UI elements:

   ```gdscript
   func update_editor():
	   var current_draft = Global.get_content_manager().get_content("current_draft")
	   $TextEditor.text = current_draft
   ```

6. Using Content for AI Prompts:
   When generating AI prompts, you can incorporate content:

   ```gdscript
   var character_description = Global.get_content_manager().get_content("main_character")
   var prompt = "Based on this character description: " + character_description + ", generate a dialogue snippet."
   var response = await Global.get_godot_claude_ai().chat(prompt)
   ```

7. Saving and Loading Content:
   You can implement methods to save content to and load content from files:

   ```gdscript
   func save_content(key: String, file_path: String):
	   var content = Global.get_content_manager().get_content(key)
	   var file = FileAccess.open(file_path, FileAccess.WRITE)
	   file.store_string(content)
	   file.close()

   func load_content(key: String, file_path: String):
	   var file = FileAccess.open(file_path, FileAccess.READ)
	   var content = file.get_as_text()
	   file.close()
	   Global.get_content_manager().add_content_source(key, content)
   ```

8. Content Synchronization:
   In a collaborative environment, you might want to synchronize content:

   ```gdscript
   func sync_content(key: String, new_content: String):
	   Global.get_content_manager().add_content_source(key, new_content)
	   Global.get_collaboration_manager().update_document(key, new_content)
   ```
