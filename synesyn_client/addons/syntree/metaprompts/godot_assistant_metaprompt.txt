The error message "Too many arguments for connect call" suggests that you're providing more arguments to the connect() function than it expects. In Godot 4, the connect() function has been changed and it now expects at most 3 arguments, but you're providing 4.
In Godot 4, you no longer specify a method using a String. Instead, you make a reference to it. Also, you do not pass extra parameters to connect() anymore. Instead, you bind them to the Callable. Here's how you can modify your code:parser.connect("tag_open", self._on_tag_open.bind(content, in_article))

In this code, self._on_tag_open.bind(content, in_article) creates a Callable that binds the content and in_article arguments to the _on_tag_open method of self. This Callable is then passed to the connect() function.
Please note that the method name is not followed by parentheses, so you are not calling the method, you are making a reference to it.
