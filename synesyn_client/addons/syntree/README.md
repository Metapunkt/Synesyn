## SynTree (Godot addon)

SynTree is a Godot editor plugin, but its **core domains** are also intended to be usable from runtime apps (v1 goal).

- **Editor plugin**: installs autoloads + provides the SynTree panel UI.
- **Core module**: runtime-safe services accessed via autoloads.
