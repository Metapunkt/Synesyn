# ReadyMade Output Directory

This directory contains all generated content from the ReadyMade A1 Synthesis Engine.

## File Structure

Each completed task generates a Markdown file with the following naming convention:
```
[Task_Name_Sanitized]_[Timestamp].md
```

## File Format

Each output file contains:

### Header Section
- **Core Idea**: The original task concept
- **Status**: Task completion status
- **Format**: Content format (e.g., "Blog post", "Video script")
- **Channel**: Target platform (e.g., "YouTube", "Instagram")
- **Cosmic Instrument**: Content creation methodology
- **Priority**: Task priority level (0-10)
- **Generated**: Timestamp when content was created
- **Completion Date**: When the task was marked as complete

### Content Sections
- **Notes**: Additional context and requirements
- **Generated Content**: The AI-generated content ready for use

## Content Persistence

- ✅ **Persistent Storage**: Files remain after Godot scenes close
- ✅ **Version Control**: Each generation creates a new timestamped file
- ✅ **Metadata Tracking**: Full task context preserved with content
- ✅ **Cross-Platform**: Standard Markdown format for universal compatibility

## Usage

1. Generated content can be directly copied for use
2. Files can be opened in any text editor or Markdown viewer
3. Content includes all context needed for publishing decisions
4. Deliverable paths are stored in task objects for reference
